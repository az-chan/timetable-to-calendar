# 课表导入（Android）

把 xlsx 课表里的每一节课写入手机系统日历（CalendarContract），生成带地点、教师、周次备注和提前提醒的日程。

- 纯离线：不联网，不申请网络权限
- 只申请「日历」读写权限，不申请存储、定位、通讯录
- 逐节写入：每节课一个独立日程，可整批撤销

> **声明**：本程序由 AI 生成。
> 目前**仅在 vivo OriginOS 7（Android 16）实测通过**；其他 Android 8.0+ 机型未做兼容性验证，可自行尝试。

---

## 一、安装

1. 从仓库 **Releases** 下载 `timetable-importer-v*.apk`；也可以按第 6 节自行构建。
2. 用文件管理器打开 APK 安装。系统提示「未知来源应用」时，按提示允许当前来源安装。
3. 首次打开会请求「日历」权限，允许即可；误点拒绝时：设置 → 应用 → 课表导入 → 权限 → 日历 → 允许。

## 二、使用步骤

1. **选择 xlsx 课表** —— 调起系统文件选择器，选中课表文件（仅支持 `.xlsx`）。
2. **（可选）点右上角齿轮调整设置**
   - 学期第 1 周周一：第 N 周据此推算日期
   - 写入起始：默认手机当前日期，只写这一天及以后的课
   - 提前提醒：不提醒 / 5 / 10 / 15 / 20 / 30 分钟 / 1 / 2 小时 / 1 天
   - 目标日历：写到哪个日历
   - 跳过已存在的同名同时段事件
3. **解析并预览** —— 显示课程门数、课次总数、将写入条数、被日期过滤掉的条数、冲突提示和前 60 条预览。
4. **写入系统日历** —— 完成后提示「已写入 / 跳过重复 / 失败」，并显示写入的目标日历。
5. 打开系统日历核对；需要撤销时点 **清除本应用写入的日程**。

## 三、课表格式要求

表头需包含下列列名（大小写、先后顺序不限）：

| 列 | 可接受的表头 | 说明 |
| --- | --- | --- |
| 星期 | `星期` `周几` `周一…周日` `星期一…星期日` | 必填 |
| 时间 | `时间` `时段` `节次` | 必填，格式 `08:00-09:35` |
| 课程 | `课程` `科目` | 必填 |
| 周次 | `周次` `周数` | 如 `1-16`、`1,3,5,7`、`1-5,7-10`、`3（4学时）` |
| 教师 | `教师` `老师` `任课` | 可选 |
| 地点 | `地点` `教室` `场地` | 可选 |

补充规则：

- 表头上方可以有标题行（例如「第 1 周（17 节课）」），会自动跳过。
- 表里若有「日期」列，则优先使用该日期，周次由日期反推。
- 地点可以按周区分：`A楼405（7,9,11,13,15周）；B-109（1,3周）`。
- 地点写成 `不用场地`、`网络授课`、`线上` 时，地点留空、原文记为备注。
- 同一时段两门课都会写入，预览里会提示冲突数量。

## 四、常见问题

- **装不上 / 提示不兼容**：确认系统为 Android 8.0 及以上；改用文件管理器直接点 APK；关闭手机管家的安装拦截后重试。
- **写入后在日历里看不到**：确认写入的日历在日历应用里没有被隐藏；云日历要同步完成后才会在其它设备出现。
- **担心重复导入**：默认会跳过「标题 + 开始时间」都相同的事件；如果改过时间，会被视为新事件，建议先清除再导入。
- **当天已结束的课也被写入**：这是预期行为（按日期过滤，不按时段）；只想从明天开始，就把「写入起始」改成明天。
- **改了提醒时间但旧日程没变**：提醒在写入时确定，改设置不会回改已写入的日程，需要清除后重新写入。

## 五、清除与卸载

- 「清除本应用写入的日程」只删除本应用创建的事件（按应用归属识别），不会影响你自己建的日程。
- 卸载应用不会删除已写入的日程；卸载前请先在应用内清除。

## 六、自行构建

不需要 Gradle，命令行即可出包（需要 JDK 17 与 Android SDK）：

```bash
python tools/fetch_toolchain.py     # 下载并解压 JDK / build-tools / platform 到 .toolchain/
python build/build_apk.py           # 产出并签名 dist/*.apk（含安装前置条件自检）
```

二次开发、文件职责与发版流程见 [HANDOFF.md](HANDOFF.md)。
